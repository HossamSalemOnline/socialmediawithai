## How this hub works

| | |
|---|---|
| 📚 **Entries** | Each X post lives in `content/` verbatim, with every link expanded. Non-English posts keep the original and add an English translation. |
| 🗂 **Topic catalogues** | GitHub topics listed in `sources/topics.json` are captured in full (every repo, not just the 20 the topic page shows) and refresh themselves every Monday. |
| 🍴 **Forks** | Tools you want to run are forked into your account and linked from their entry. Use "Sync fork" on GitHub for the author's updates. |
| 🌐 **Website** | `docs/` is a designed site with a copy button on every prompt and command. |
| ⚙️ **Automation** | On every push GitHub rebuilds the README, REPOS.md and the website; every Monday it also refreshes the topic catalogues. |

## Repository layout

```text

├── README.md                  ← this page (the Entries section is generated)

├── tools/
│   ├── refresh_topics.py      ← pulls every repo in each topic
│   ├── x_article_to_md.py     ← converts a scraped X Article to Markdown
│   ├── fetch_media.py         ← stores media in docs/media/
│   └── build_site.py          ← rebuilds docs/, REPOS.md and the README sections
├── .github/workflows/update.yml
└── docs/                      ← website
```
